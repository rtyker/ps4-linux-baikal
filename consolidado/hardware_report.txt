RESUMO PARA DESENVOLVIMENTO DE KERNEL/DRIVERS
================================================================================

Alvos principais para drivers customizados:
1. AMD Gladius GPU (0x1002:0x9924) - Driver amdgpu funcional, mas com patches custom
2. Sony Baikal chip - Multiplos perifericos (Ethernet, SATA, USB, DMA, SD/MMC, Memoria, ACPI)
3. xhci_aeolia - USB 3.0 custom
4. baikal_pcie - PCIe glue custom
5. sdhci-pci - SD/MMC host
6. Aeolia Ethernet - Rede custom
7. Aeolia SATA - Armazenamento
8. Aeolia ACPI - Power management

Pontos de atencao:
- IOMMU unico para todos os dispositivos Baikal (group 0)
- IRQ routing via IR-Baikal-MSI (nao PCI-MSI padrao)
- TSC como unico clocksource estavel
- Sem cpufreq scaling (freq fixa ou firmware-controlled)
- Console serial ativo (ttyS0 115200n8)
- netconsole para debug remoto
